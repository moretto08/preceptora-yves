# Preceptora Yves

Página estática pronta para publicação na Vercel.

## Publicação

1. Crie um repositório vazio no GitHub.
2. Envie este conteúdo para a branch `main`.
3. Na Vercel, importe o repositório e selecione **Other** como framework. Não há comando de build nem diretório de saída a configurar.

Antes de publicar, troque os links `#` em `index.html` pelos endereços reais de WhatsApp, YouTube e Substack.
